CUD CHEDS Demo 4 v10

Organizer shared-link workflow:
1 Create Event.
2 Receive Event ID + Attendance QR.
3 Download QR.
4 QR opens participant attendance sheet.
5 Later use Find My Event with Event ID + creator CUD email.
6 Submit Manual Attendance + Evidence + Remarks.
7 Final submission locks the post-event record.
8 Organizer can retrieve/view locked event but cannot resubmit or edit.
9 IRP portal can edit/correct locked records.
10 IRP dashboard supports School / Department / Program / Status filtering and CSV export.

Static demo uses browser localStorage. Production XAMPP version will use MySQL and server-side authorization.
