V18 - Automatic Arabic translation for Event Name + Event Description

Automatic translation now applies to:
1. Event Name English -> Event Name Arabic
2. Event Description English -> Event Description Arabic

Both Arabic fields remain editable for organizer review/correction.
The 255-character description limit is retained.

All existing working functions from v17 remain unchanged:
- School login
- IRP login
- event creation
- Event ID
- working same-page Attendance QR
- QR PDF
- QR attendance
- manual attendance
- evidence
- post-event locking
- IRP dashboard / filters / export / correction

Demo translation requires internet access and uses a public translation endpoint.
