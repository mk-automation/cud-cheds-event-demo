CUD CHEDS GITHUB DEMO - QR ATTENDANCE

This is a static GitHub Pages demonstration.

Demo workflow:
1. Complete Pre-Event form.
2. Submit -> Event Code & Attendance QR page.
3. QR points to the Participant Attendance page (#attendance).
4. Participant submits attendance.
5. Demo stores attendance in browser localStorage and increments QR Attendance.
6. dashboard-demo.html shows QR Attendance + Manual Attendance = Total Attendance.

For the real XAMPP/MySQL application use the XAMPP v4 package. In the real version,
each QR submission is stored in the qr_attendance database table.
